# Output files

The default workflow writes sample-level and cohort-level outputs under
`results/`.

## Transcriptome outputs

| Path pattern | Description |
| --- | --- |
| `results/gex/{study}_{sample}_all_cells.tsv` | All-cell metadata with UMAP and annotation. |
| `results/gex/{study}_{sample}_B_cells.tsv` | B-cell metadata with B-cell subtype annotation. |
| `results/gex/{study}_{sample}_all.h5ad` | Processed all-cell AnnData object. |
| `results/gex/{study}_{sample}_b.h5ad` | Processed B-cell AnnData object. |
| `results/gex/{study}_{sample}_b_cell_embedding.tsv` | B-cell UMAP coordinates and Cell Subtype labels for PostgreSQL. |
| `results/gex/{study}_{sample}_b_marker_expression.tsv` | Marker-gene expression cache for feature plots and dot plots. |
| `results/gex_de/{study}_{sample}_clone_gene_expression_summary.tsv` | Clone-level expression summaries for BCR-transcriptome analysis. |
| `results/gex_zarr/{study}_{sample}_b.zarr` | Zarr store for complete B-cell expression access. |
| `results/gex_zarr/{study}_{sample}_b_zarr_manifest.tsv` | Zarr manifest for database loading. |

## BCR outputs

| Path pattern | Description |
| --- | --- |
| `results/changeo/{study}_{sample}_igblast.tsv` | IgBLAST output from Change-O AssignGenes. |
| `results/changeo/{study}_{sample}_db.tsv` | Change-O database generated by MakeDb. |
| `results/changeo/{study}_{sample}_db_germ.tsv` | Germline-reconstructed Change-O table. |
| `results/changeo/{study}_{sample}_SHM.tsv` | SHM output generated by ShazaM/Alakazam. |
| `results/changeo/{study}_{sample}_SHM_c_call.tsv` | SHM table with constant-region calls supplemented from Cell Ranger. |
| `results/bcr/{study}_{sample}_SHM_paired.tsv` | Cell-level paired heavy/light BCR table. |
| `results/bcr/{study}_{sample}_SHM_IGH.tsv` | Heavy-chain BCR table. |
| `results/bcr/{study}_{sample}_clone.tsv` | Clone-labeled heavy-chain records. |
| `results/bcr/{study}_{sample}_bcr.json` | BCR JSON file for download/reuse. |

## Repertoire and lineage outputs

| Path pattern | Description |
| --- | --- |
| `results/repertoire/{study}_{sample}_vdj_usage.tsv` | Per-sample heavy-chain V, J and VDJ usage summaries. |
| `results/repertoire/diversity.tsv` | Per-sample clone diversity metrics. |
| `results/repertoire/public_clonotypes.tsv` | Disease/study-aware Public Clonotype table. |
| `results/repertoire/public_network.tsv` | Public Clonotype subject/sample/clone membership table. |
| `results/repertoire/clone_members.tsv` | Public Clonotype member records. |
| `results/lineage/{study}_{sample}_lineage_tree.tsv` | Lineage tree node table. |
| `results/lineage/{study}_{sample}_lineage_edge.tsv` | Lineage tree edge table. |
| `results/lineage/{study}_{sample}_lineage.json` | Cytoscape-compatible lineage JSON. |
| `results/cdr3_network/{study}_{sample}_cdr3_network.json` | Sample-level CDR3 similarity network JSON. |

## Database output

| Path | Description |
| --- | --- |
| `results/database_loaded.txt` | Marker file created after successful PostgreSQL loading. |
